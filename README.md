# Portafolio de Bramdon Aguilar

Portafolio web de Bramdon Aguilar, Creative Producer (Maracay, Venezuela).
Sitio estático: HTML, CSS y JavaScript, sin dependencias de compilación.

- **Sitio:** https://aguilarzrw.github.io/bramdon-portafolio/
- **Estructura:** `index.html`, `img/` (fotos y logos), `video/` (clips y video de fondo)
- **Logos de marcas:** `img/logos/` (ver `LEEME.txt`)
- **Logos de herramientas:** `img/tools/` (ver `LEEME.txt`)
- **Vista previa al compartir (WhatsApp, etc.):** `og-image.jpg`, 1200×630. Se actualiza reemplazando ese archivo; las redes sociales pueden guardar la versión anterior en caché unos días.
